# Skerry - 视觉小说管理与启动平台功能全景介绍

> **产品版本**：v1.0.0-beta  
> **产品定位**：专为视觉小说（Galgame / Visual Novel）爱好者打造的高颜值、高性能、多源聚合的本地媒体库管理、时序追踪与启动平台。

---

## 一、主页控制台 (Play Deck)

1. **C 位焦点主卡片 (Hero Card)**
   - 动态横幅沉浸展示上次游玩的游戏，支持大封面与游戏艺术背景切换。
   - 保持优雅视觉比例，窗口缩放时平滑适配，拒绝画面挤压变形。
   - 一键启动游戏、即时显示上次游玩时间与当前状态。
   - 支持双击窗口标题栏无缝全屏 / 窗口化切换。

2. **多维数据小卡片矩阵**
   - **本月点亮热力图 (Activity Grid)**：固定 31 格日历式点亮网格，直观展示本月每日游玩轨迹，配备对应游玩时长梯度的渐变色阶图例。
   - **核心统计四卡片**：累计游戏次数、今日游戏时长、累计总时长、存档备份数，在深色与浅色模式下具备独立层次渐变底色与呼吸微光。
   - **随机游戏推荐 (Random Picker)**：自适应封面比例展示，带平滑翻转切换动画，杜绝卡片撑爆或空白突兀。
   - **最近游玩轨迹**：清晰记录近期游玩时间线，自适应分辨率动态调整排版与文字字号。

---

## 二、游戏库与收藏夹 (Game Library & Collections)

1. **灵活的视觉呈现**
   - 高清网格封面流，支持封面比例自适应，悬停状态优雅微动。
   - 支持 80% ~ 150% 界面无级缩放，完美兼顾 1080P、2K 及更高分辨率屏幕。

2. **深度分类与管理**
   - **自定义多收藏夹**：自由建立游戏归类分组，支持手动拖拽自由排序。
   - **高级检索与筛选**：按开发商、发售年份、游玩状态（想玩/在玩/通关/搁置）、评分区间、标签进行多维度筛选。
   - **多选批量操作**：支持批量更改游戏状态、批量更新元数据、批量分类归档。

3. **云端与虚拟游戏库 (Cloud Collections)**
   - 支持导入非本地安装的云端游戏收藏（如 Bangumi、VNDB、光凪的在玩与想玩列表），建立个人完整游戏编年史。

---

## 三、多源元数据刮削中枢 (Metadata Engine)

支持目前市面上最全面的 7 大 Galgame 元数据信息库聚合：

| 数据源 | 特色优势 | 认证方式 | 当前状态 |
|:---|:---|:---|:---|
| **鲲 Galgame (KunGal)** | 全网最新中文视觉小说数据库，中文译名最地道，补丁与平台收录详尽 | 免登录 OpenAPI v1 | **已全面接入 (v1)** |
| **Bangumi (番组计划)** | 庞大华语 ACG 社区评级与短评体系 | OAuth 2.0 授权 | 完美支持双向同步 |
| **VNDB** | 全球最权威视觉小说数据库，全量标签、CG、分级、发售信息 | Token 授权 / 匿名 | 完美支持 |
| **YMGal (月幕 Galgame)** | 本土化中文简介、汉化补丁信息、制作人员名单 | 公开 API | 完美支持 |
| **光凪 (Hikarinagi)** | 中文同好社区评分、在线收藏夹 | OAuth 授权 | 完美支持 |
| **DLsite** | 官方分级标签、RJ号检索、全年龄/R18 同人游戏信息 | 公开刮削 | 完美支持 |
| **ErogameScape (批评空间)**| 日本硬核批评空间得点、中央值、纯日系玩家评分体系 | 公开刮削 | 完美支持 |

- **混合源智能合并 (Mixed Source)**：自动提取各源优势字段（如 VNDB 的高清封面 + KunGal/YMGal 的精校中文标题 + Bangumi 综合评分），生成最佳本地元数据。
- **关联 VNDB 自动增强**：鲲源条目自动抓取关联的 VNDB 条目进行信息与标签补强。

## 四、游戏详情与资产画廊 (Detail View & Gallery)

1. **详情展示**
   - 沉浸式宽幅头图底图，支持自定义更换底图与横向/纵向显示偏移调整。
   - 制作人员 (Staff) 分工列表（剧本、原画、音乐、监督）。
   - 评分多徽章胶囊（多源评分并列对比，深浅色独立高对比度配色）。
   - 游戏标签云（按剧透等级与敏感等级过滤）。
2. **多源截图与 CG 画廊**
   - 支持从各数据源抓取高清预览截图，支持大图画廊无缝浏览。
3. **分段数据统计**
   - 记录该游戏的游玩时间段分布与历史会话记录。

---

## 五、进程监控、存档保护与转区工具 (Runtime & Tools)

1. **精准进程追踪**
   - 启动游戏时自动识别主进程并开始精确计时，支持多进程检测与非正常退出兜底。
2. **自动化存档防丢备份**
   - 游戏启动与退出时自动扫描存档目录，生成带时间戳的增量或快照压缩包。
   - 支持一键备份、历史备份点查看与存档恢复。
3. **原生转区与画质超分辨率增强集成**
   - 支持一键绑定 **Locale Emulator (LE)** 实现日文环境转区启动。
   - 支持一键集成 **Magpie** 实现全屏 FSR / Lanczos 高清插值算法放大。

---

## 六、游戏总结仪表盘 (Game Summary / Annual Report)

1. **全时间段与单年度切换**：支持浏览所有年份总览或指定年份的游玩年报。
2. **核心指标仪表盘**：
   - 今年游玩时长 / 历史总时长对比（英文化紧凑排版）。
   - 8 项关键数据卡片：新增游戏、玩过游戏、通关游戏、活跃天数、月均时长、日均时长、最长连续游玩、峰值游玩月份。
3. **游玩节奏与周分布**：
   - 12 个月的月度节奏柱状图。
   - 一周 7 天的游玩偏好热力分布，无数据时展示优雅磨砂空占位卡片。

---

## 七、多线程下载管理器 (Downloader)

- 内置轻量高效的多线程分块下载引擎。
- 支持断点续传、实时下载速率折线图、并发任务队列控制。

---

## 八、界面视觉与系统级特性 (Craft & System)

1. **深浅双色主题与径向过渡动画**
   - 浅色切深色：以按钮为中心向全屏扩散的涟漪过渡。
   - 深色切浅色：从全屏向右上角平滑收敛的收缩过渡。
   - 图标旋转联动动画，消除主题切换窜色与闪烁。
2. **窗口状态持久记忆**
   - 智能记录上次关闭应用时的窗口尺寸与屏幕位置，再次启动自动复原，兼顾防多屏漂移边界检测。
